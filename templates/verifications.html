Verification Process

Discord users can verify their Roblox accounts by following these steps:

  1. Use the /verify command in Discord with your Roblox username
  2. Add the provided verification code to your Roblox profile description
  3. Use the /check command to complete verification

Once verified, users can use /whois to check verification status.
